# ce12-3.1-demo
GitHub Actions workflows for CICD and Terraform automation.

📘 What I Learned
- Set up and structured GitHub Actions workflows for CI/CD automation
- Understood workflow triggers such as push events and manual dispatch
- Integrated AWS securely using GitHub Secrets and configured environment variables
- Automated infrastructure deployment using Terraform (init, plan, apply, destroy) via GitHub Actions
- Gained understanding of Terraform remote state management using an S3 backend
- Learned the importance of backend prerequisites (S3 bucket must exist before init)
- Implemented separation of deployment and teardown workflows for safer infrastructure management
- Used GitHub Variables to manage configurable values like AWS region
- Understood the difference between GitHub Secrets and Variables in CI/CD pipelines
- Developed foundational knowledge of Infrastructure as Code (IaC) and CI/CD practices
